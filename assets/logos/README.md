# Maker Faire Kochi vector logos

Converted from the vector PDFs in the user-supplied `MF_Kochi_Logos.zip`. All lettering, including Kochi, is outlined; these SVGs contain no raster images and require no external fonts. Original page dimensions and logo proportions are preserved.

## Files

Each layout (`long`, `border`, `square`) has three versions:

- `MF_Kochi_Logo_<layout>.svg`: original PDF colours and white panels.
- `MF_Kochi_Logo_<layout>_black.svg`: solid black artwork on transparency.
- `MF_Kochi_Logo_<layout>_white.svg`: solid white artwork on transparency, for dark backgrounds.

The monochrome versions have transparent border interiors and letter counters. The bordered layout retains its original outer spacing. Empty PDF notes and guides have been omitted.
