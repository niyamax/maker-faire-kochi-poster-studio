# Sample images

Generated demonstration assets for Poster Studio:

- `workshop.png` — hands assembling a mechanical prototype, for Image window.
- `robot.png` — a transparent tabletop maker robot, for Object cut-out.
- `studio-robot.png` — a finished yellow tracked robot with studio lighting and a transparent background, for Object cut-out.

These sample images are provided under the repository's MIT licence. They illustrate sample maker projects.
