# Sample images

Generated demonstration assets for Content Studio and Poster Studio:

- `workshop.png` — AI-generated editorial-style workshop scene of hands assembling a mechanical prototype, for Image window and content packs. The source demonstration image was edited with image generation to use bare brushed aluminum, charcoal resin, brass, and natural plywood parts while preserving the hands, tools, independent material colours, and workshop daylight. It illustrates a fictional sample project, not documentary coverage of a real event.
- `robot.png` — a transparent tabletop maker robot, for Object cut-out.
- `studio-robot.png` — a finished yellow tracked robot with studio lighting and a transparent background, for Object cut-out.

These sample images are provided under the repository's MIT licence. They illustrate sample maker projects.
